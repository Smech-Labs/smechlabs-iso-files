# Smech Labs ISO Files

Distribution point for all Smech Labs OS release ISOs (SmechOS, SmechVisor,
and future projects) as GitHub Releases.

ISOs are attached as release assets, not committed to git history. Each
release tag documents the SHA-256 checksum for the ISO it ships -- always
verify before booting or installing.

See the [SmechOS site](https://os.smech.xyz/downloads.html) for the current
recommended download and release notes.
